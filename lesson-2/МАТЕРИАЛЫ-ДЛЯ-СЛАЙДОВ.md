# Материалы для колоды встречи 2 · задание для Claude Code на ПК ведущего

Колода не показывает заглушек. Где нужен настоящий снимок или текст, слайд работает в варианте без него, пока материал не положен. Этот файл — что именно собрать, откуда и куда положить. Делает Claude Code на домашнем ПК ведущего (там есть вход во все кабинеты и файлы); пароли за ведущего не вводить, если сессии нет — попросить ведущего войти.

## Общие правила

- Снимки: PNG, в 2× от размера рамки на слайде (размеры ниже), без системных панелей и курсора. Снимать окно или область, не весь экран.
- Обезличить до сохранения: имена и фамилии участников, адрес объекта, телефоны, почта, Telegram ID, ключи API и токены, суммы из личных счетов. Закрасить сплошным цветом или обрезать; размытие не годится.
- Класть в `lesson-2/deck/real/<имя>.png`. После этого внести имя (без `.png`) в `lesson-2/deck/data.js` → `realShots`. Без записи в `realShots` снимок не подключится — так в консоли нет ошибок про отсутствующие файлы.
- Тексты и цифры — только в `lesson-2/deck/data.js`, не в `index.html`.
- Проверка после каждого пункта: открыть `lesson-2/deck/index.html#N` в Chrome, пролистать шаги слайда; снять скриншоты 1600×900 командой из README и посмотреть глазами.
- Данные участников в репозиторий колоды не попадают: только обезличенные снимки и тексты.
