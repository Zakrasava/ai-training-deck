## Как устроена колода

- **Сцена** 1600×900, масштабируется под окно; всё в координатах 1600×900. Минимальный кегль 18 px.
- **Слайд** — `<section class="slide" id="sN" data-n="N" data-block="Блок" data-steps="K">`. Порядок листания = порядок в DOM. `data-block` — подпись внизу слева.
- **Шаги внутри слайда**: элементы `.fx` (появление снизу), `.fx.fade` (только прозрачность), `.mask > span` (строка заголовка из клип‑маски) получают класс `.on`, когда шаг ≥ `data-on` (по умолчанию 0). `data-d` — задержка в мс в момент появления.
- **Хуки** `window.SLIDE_HOOKS.sN = (el, s, instant) => {}` — для линий маршрута, счётчиков, таймера. `s = -1` — сброс перед первым входом. Помощники: `draw(path, длина)` дочерчивает линию, `lenTo(path, x, y)` — длина до точки, `countUp(el, instant)`.
- **Клавиши слайда** `window.SLIDE_KEYS.sN = k => {}` — цифры 1–9 (сейчас только слайд 14: проверки 1–4).
- **Поведение**: → / пробел / Enter / клик по правой четверти / свайп влево — следующий шаг, потом следующий слайд; ← — назад. Первый заход — анимация входа один раз; повторный заход или назад — слайд сразу собран. Переход между слайдами — сдвиг сцены вдоль маршрута и отрезок по нижней полосе.
- **Нижняя полоса**: ≡ (оглавление, `M`, Esc закрывает) · блок · маршрут колоды · номер · полный экран (`F`).
- **Адрес**: `#8` — слайд 8; `#8.2` — слайд 8 на шаге 2 (для скриншотов). `?static` — без движения. `N` — заметки ведущего (из `<aside class="notes">`, в публичной сборке их нет).
- **prefers-reduced-motion** отключает движение; портрет на телефоне — подсказка «поверните телефон».
