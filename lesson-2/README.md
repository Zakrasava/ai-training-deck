Сценарий, раскадровка и бриф на каждый слайд лежат в репозитории программы (`ai-corp-training/docs/программа/занятие-2-подготовка-2026-10-25/`), там же разбор наметок. Здесь только публичная часть без данных участников.

## Как снять скриншот концепта

```
chrome --headless=new --disable-gpu --hide-scrollbars --window-size=1600,900 --virtual-time-budget=8000 --screenshot=concepts/shots/a.png concepts/a.html
```

Шрифты на страницах концептов грузятся с Google Fonts; в финальной сборке колоды они будут лежать рядом.
