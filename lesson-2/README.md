# Встреча 2 · «Свой помощник: от ТЗ до запуска»

Отдельная папка для колоды второй встречи. Дизайн первой встречи (`v5-src`, `v3`–`v13`) здесь не используется: другие шрифты, другая фишка, сборка с нуля.

## Состояние на 25 октября 2026

- `index.html` — галерея трёх направлений дизайна на одном ключевом слайде («Как устроен помощник ТЗ»): https://zakrasava.github.io/ai-training-deck/lesson-2/
- Третий раунд, своё направление (26.10, ночь): `concepts/g.html` «Стол ведущего ночью» — камера над столом под лампой, остановки по стрелке: заголовок на столе, телефон с реальными репликами бота, планшет с окном агента, распечатанное ТЗ; `?p=0.33` открывает нужную остановку. Без чужих клипов.
- Второй раунд (25.10, вечер; клипы из промптов пользователя понравились сами по себе, но сюда не подходят): `concepts/d.html` «Поезд» (клип скрабится стрелками и колесом, без прокрутки страницы; `?p=0.5` открывает нужную точку), `concepts/e.html` «Дельта», `concepts/f.html` «Тёплая ночь». Клипы из промптов пользователя лежат в `assets/` (поезд 1080 и 720, постер, дельта, ночной стол).
- Первый раунд, отклонён: `concepts/a.html` «Ночной рейс», `concepts/b.html` «Чертёж», `concepts/c.html` «Консоль». Скриншоты 1600×900 всех концептов в `concepts/shots/`.
- Колода ещё не собиралась. Порядок по брифу: бриф → раскадровка → выбор направления → сборка сценами по 3–5 слайдов с рендером после каждой.

Сценарий, раскадровка и бриф на каждый слайд лежат в репозитории программы (`ai-corp-training/docs/программа/занятие-2-подготовка-2026-10-25/`), там же разбор наметок. Здесь только публичная часть без данных участников.

## Как снять скриншот концепта

```
chrome --headless=new --disable-gpu --hide-scrollbars --window-size=1600,900 --virtual-time-budget=8000 --screenshot=concepts/shots/a.png concepts/a.html
```

Шрифты на страницах концептов грузятся с Google Fonts; в финальной сборке колоды они будут лежать рядом.
