## Как собрать, показать и править (состояние на 26 октября 2026)

- **Колода** — 23 слайда, направление И «Маршрутный лист», утверждена ведущим 26.10; правки ведущего по слайдам внесены вечером 26.10 (слайд «Задание» убран: бот больше не используется, он только показал структуру ТЗ; добавлен слайд 19 «Одно ТЗ — два решения» — развилка на кейсе рейсов). Только урок 2, без упоминаний следующей встречи. Устройство и правила — `ПЕРЕДАЧА-НА-ДОРАБОТКУ.md`, бриф — `ЗАДАНИЕ-ДЛЯ-ДИЗАЙНА.md`, что снять и куда положить — `МАТЕРИАЛЫ-ДЛЯ-СЛАЙДОВ.md`.
- **Рабочая версия** с заметками ведущего: `deck/index.html` (`deck.css`, `deck.js`, `data.js`, `qr.js`, шрифты из `../fonts/`). Открывается с диска, интернет не нужен.
- **Публичная сборка**: из папки `lesson-2` выполнить `node tools/build-public.mjs` → `lesson-2/index.html` без заметок (подключает `deck/` через `<base href="deck/">`). Пересобирать после каждой правки `deck/index.html`. Адрес: https://zakrasava.github.io/ai-training-deck/lesson-2/ (корень сайта ведёт на встречу 1).
- **Показ**: → / пробел / Enter / клик по правой четверти / свайп влево — следующий шаг, затем следующий слайд; ← — назад; `#8` — слайд 8, `#8.2` — слайд 8 на шаге 2; `M` или «три полоски» — оглавление (Esc закрывает); `F` — полный экран; `N` — заметки ведущего (только в рабочей версии); `?static` — без движения. Слайд 13 — без таймера. На слайде 14 клавиши 1–4 зажигают проверки (первое нажатие — сошлось, второе — не сошлось, третье — сброс). Повторный заход открывает слайд собранным; `prefers-reduced-motion` отключает движение; в портрете на телефоне — подсказка повернуть.
- **Где менять** — только `deck/data.js`, в `index.html` цифр нет:
  - `botLink` и `qrLabel` — ссылка и подпись QR на слайде 23 (решение ведущего 26.10: Telegram ведущего `https://t.me/zakrasava`, не бот). QR рисуется сам; без ссылки вида `https://t.me/…` карточки с QR на слайде нет.
  - `participants`, `packs`, `halfway` — заголовок слайда 2 (в списке задач только те, кто ответил на первый вопрос); `calls`, `cost`, `perPeople`, `costPerCall`, `costPerHead` — слайды 4 и 7; `callsPerInterview`, `costPerInterview`, `sonnetPerCall`, `opusPerCall`, `subsMonthly` — блок «Посчитано ещё на тестах» на слайде 7; `demoTime`, `demoFolder` — плашка на титуле; `demoFile` — имя файла в рамке слайда 14; `agentTimes` — время девяти шагов на слайде 15 (пока `null` — время не показывается); `tasks` — строки задач на слайдах 2 и 9 (текст, направление, статус, штамп доступа, карточка «что нужно / где упирается / как решаем»); `dialog` — реплики слайда 6.
  - Пересчёт цифр на день эфира по базе бота (только локально, `ai-corp-training-bot/data/bot.db`): участники — `select count(*) from participants`; пакеты — `select count(*) from participants where status='done'`; на полпути — остальные; обращения и стоимость — `select count(*), round(sum(usd),2) from costs` (по моделям: `group by model`).
  - `realShots` — имена настоящих снимков из `deck/real/*.png` без расширения (`14-result`, `12-gsp-cabinet`, `20-omnerio`, `20-gsp`). Снимок подключается только когда файл лежит в папке и имя внесено в список; иначе слайд показывается в варианте без снимка. Заглушек нет.
- **Демо (слайды 1, 14, 15)** — папка агента `C:\Users\User\Projects\demo\parking-model` (имя на плашке титула — `demoFolder`): пакет Александра из бота (`ТЗ.md`, `инструкция-проекта.md`, `как-запустить.md`, `образец-результата.md`), исходная модель в `образцы/`, правила агента `CLAUDE.md` (работа в копии `сравнение_вариантов.xlsx`, без адреса на экране, пересчёт формул через Excel COM, журнал шагов с временем в `журнал.md`). Запуск на эфире: открыть Claude Code в этой папке и вставить В1 из сценария; агент останавливается на цене перегородок и ждёт «подтверждаю». Репетиция 26.10 (13 минут, остановка на цене перегородок, четыре проверки сошлись) — результат и журнал в `demo\репетиция-26.10\`, папка эфира чистая; снимок листа «Сравнение» из репетиции — `deck/real/14-result.png`, время шагов — `agentTimes`.
- **Проверки** (из папки `lesson-2`): `node tools/check.cjs` и `node tools/check.cjs index.html` — три размера, текст за сценой, ошибки консоли, листание (нужен Playwright: `npm i -D playwright` в отдельной папке и `npx playwright install chromium`, путь к модулям — через `NODE_PATH`); `powershell -ExecutionPolicy Bypass -File tools\shots.ps1` — скриншоты всех шагов в `deck/shots/` (число шагов слайдов задано в скрипте, `$steps`). Перед push — ревью Codex по diff.

