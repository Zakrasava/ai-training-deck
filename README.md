# ИИ как новый сотрудник — презентация встречи 1

HTML-презентация для корпоративного обучения работе с ИИ. Открывается в браузере, работает без сборки и внешних запросов: шрифт и стили лежат рядом.

## Как показывать

- Открыть `index.html` или опубликованную страницу, нажать `F` для полного экрана.
- Стрелки, пробел, клики по краям экрана и свайпы листают слайды. `N` открывает заметки ведущего, `?` справку.
- Номер слайда хранится в адресе: `#8` открывает восьмой. Удобно для возврата после живого показа экрана.
- Печать в PDF: `Ctrl+P`, альбомная ориентация, фон включён.

## Структура

- `index.html` — слайды и заметки ведущего (блоки `.note` внутри каждого слайда, на экране не видны).
- `styles.css` — дизайн-система: палитра, типографика, карточки, стеклянные кубы, анимации появления.
- `deck.js` — навигация, прогресс, заметки, полный экран.
- `assets/fonts/` — Onest (SIL Open Font License), кириллица и латиница.

Все примеры в слайдах вымышленные. Названия моделей и цены намеренно не указаны: они меняются, их называет ведущий по состоянию на день встречи.

## Версия v7 (архив): светлая инженерная

Адрес: https://zakrasava.github.io/ai-training-deck/v7/. Выбрана пользователем из трёх концепций (`concepts/`): «инженерный, но светлый». Светлый фон с тонкой сеткой, белые панели с рамкой 1px, один холодный акцент, шрифт Inter Tight (локально), окна интерфейса как есть, нумерованная повестка с таймингом на разделах. Без WebGL, без кубов, без звёзд: титул показывает письмо поставщику в окне чата. Исходники по‑прежнему `v5-src/`, сборка кладётся в `v7/`; витрина из сборки исключена (код компонентов остаётся в `v5-src/src/bits/`).

## Версия v6 (архив)

Адрес: https://zakrasava.github.io/ai-training-deck/v6/. Исходники те же `v5-src/`, сборка теперь кладётся в `v6/`; папка `v5/` заморожена для сравнения. Отличия от v5: фоны слайдов идут навылет до краёв окна при любых пропорциях (без «островов» 16:9), фоны React Bits (шёлк на разделах, нити, поле точек, луч на финале) грузятся отдельными чанками только на своём слайде, иконки lucide в карточках, акцентный градиент на ключевых фразах.

## Витрина компонентов (v6/showcase.html)

Страница для выбора эффектов: https://zakrasava.github.io/ai-training-deck/v6/showcase.html. Слева список из 107 компонентов React Bits (MIT, код лежит в `v5-src/src/bits/`), справа сцена 1600×900 в палитре колоды с текстом слайда поверх. Стрелки листают, пробел отмечает «беру», `T` прячет текст слайда. Отмеченные собираются в поле «Мой выбор», кнопка «Скопировать» даёт список для чата. Выбор хранится в браузере.

Сборка: `cd v5-src && npm run build` собирает и колоду (`index.html`), и витрину (`showcase.html`) в `../v6`.
